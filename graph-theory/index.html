Graph Theory and Combinatorics

1. Graph, multigraph, subgraph
Graph
A finite undirected graph \(G=(V,E)\) consists of a vertex set \(V\) and an edge set \(E\). In a simple graph, each edge is a two-element subset of \(V\), so loops and parallel edges are excluded. The order is \(|V|\); the size is \(|E|\).
Multigraph
A multigraph may have more than one edge with the same pair of ends. The parallel edges remain distinct.
Subgraph
\(H=(V_H,E_H)\) is a subgraph of \(G=(V,E)\) if \(V_H\subseteq V\), \(E_H\subseteq E\), and every edge in \(E_H\) has both ends in \(V_H\).
Induced and spanning
For \(S\subseteq V\), the induced subgraph \(G[S]\) contains \(S\) and every edge of \(G\) whose ends both lie in \(S\). A subgraph is spanning if its vertex set is all of \(V\).
Adjacent and incident
Two vertices are adjacent if an edge joins them. A vertex and edge are incident if the vertex is one of the edge's ends.
2. Degree and regular graphs
Neighbourhood
The neighbourhood \(N(v)\) is the set of vertices adjacent to \(v\). For \(S\subseteq V\), \(N(S)=\bigcup_{v\in S}N(v)\).
Degree
The degree \(d(v)\) is the number of edges incident with \(v\). In a simple graph, \(d(v)=|N(v)|\). The handshaking lemma states \(\sum_{v\in V}d(v)=2|E|\).
Regular graph
A graph is r-regular if every vertex has degree \(r\). A 3-regular graph is cubic.
3. Walk, trail, path, circuit, cycle
Walk
A walk of length \(k\) is a sequence of vertices \(v_0,v_1,\ldots,v_k\) such that consecutive vertices are joined by an edge. Vertices and edges may repeat.
Trail
A trail is a walk with no repeated edge.
Path
A path is a walk with no repeated vertex.
Closed walk / closed trail
A walk or trail is closed if its first and last vertices are equal.
Cycle
A cycle is a closed walk whose vertices are distinct except that the first and last coincide. In a simple graph its length is at least 3.
4. Connected graphs
Connected
A graph is connected if every pair of vertices can be joined by a path. A connected component is a maximal connected subgraph.
Vertex-connectivity \( \kappa \)
For a non-complete connected graph, \(\kappa(G)\) is the minimum number of vertices whose deletion disconnects the graph. Set \(\kappa(K_n)=n-1\). A graph is 2-connected if it has at least three vertices and remains connected after the deletion of any one vertex; equivalently, it has no cut-vertex.
Independent set
A vertex set is independent if no two of its vertices are adjacent. The maximum size of an independent set is the independence number \(\alpha(G)\).
Tree
A tree is a connected acyclic graph. Equivalently, it is a connected graph on \(n\) vertices with \(n-1\) edges, or a graph in which every pair of vertices has a unique path.
5. Eulerian trail, circuit, graph
Eulerian trail
A trail that contains every edge of the graph exactly once.
Eulerian circuit
A closed Eulerian trail: it starts and ends at the same vertex and uses every edge exactly once.
Eulerian graph
A connected graph with at least one edge that has an Eulerian circuit.
Euler's theorem (1736), circuits
A connected graph with at least one edge has an Eulerian circuit if and only if every vertex has even degree.
6. Hamiltonian and uniquely Hamiltonian
Hamiltonian cycle
A cycle containing every vertex of the graph. A graph containing such a cycle is Hamiltonian.
Hamiltonian path
A path containing every vertex of the graph exactly once.
Uniquely Hamiltonian graph
A graph with exactly one Hamiltonian cycle, where cycles are considered the same if they have the same edge set.
Hypohamiltonian
Non-Hamiltonian, but \( G - v \) is Hamiltonian for every vertex \( v \). Fleischner's construction starts from a cubic hypohamiltonian graph with a dominating cycle; Petersen is the usual example.
7. Dominating cycle
Dominating cycle
A vertex set \(D\) is a dominating set if every vertex outside \(D\) has a neighbour in \(D\). A dominating cycle is a cycle whose vertex set is a dominating set.
8. Automorphisms and isomorphism
Graph automorphism
An automorphism of \( G \) is a bijection \( \varphi \colon V(G) \to V(G) \) such that, for all \( u, v \in V(G) \), \[ uv \in E(G) \iff \varphi(u)\varphi(v) \in E(G). \] Thus \( \varphi \) preserves adjacency. The set of all automorphisms is a group, written \( \mathrm{Aut}(G) \).
Hamiltonian cycle under automorphism
If \( C \) is a Hamiltonian cycle and \( \varphi \in \mathrm{Aut}(G) \), the image \( \varphi(C) \) is a Hamiltonian cycle with edge set \( \{ \varphi(u)\varphi(v) : uv \in E(C) \} \). Two Hamiltonian cycles may lie in the same \( \mathrm{Aut}(G) \)-orbit without being equal as edge sets. Uniquely Hamiltonian means exactly one Hamiltonian cycle as a subgraph, not uniqueness up to automorphism.
Isomorphism
A bijection \( f \colon V(G) \to V(H) \) such that \( \{u,v\} \) is an edge of \(G\) if and only if \( \{f(u), f(v)\} \) is an edge of \(H\). Then \(G\) and \(H\) are isomorphic, written \(G \cong H\).
9. Graph types
Complete graph \( K_n \)
Every pair of distinct vertices is joined by exactly one edge. \( K_n \) is \( (n-1) \)-regular and has \( \binom{n}{2} \) edges.
Path graph \( P_n \)
A path on \( n \) vertices (\( n-1 \) edges).
Bipartite graph
The vertex set splits as \( V = A \cup B \) with \( A \cap B = \emptyset \), and every edge has one end in \( A \) and one end in \( B \). Equivalently, \( G \) contains no odd cycle.
Complete bipartite graph \( K_{s,t} \)
Every vertex of a part of size \( s \) is joined to every vertex of a part of size \( t \). The graph \( K_{1,n} \) is a star.
Complement \( \overline{G} \)
Same vertex set as \( G \); two distinct vertices are adjacent in \( \overline{G} \) if and only if they are not adjacent in \( G \). (Defined for simple graphs.)
10. Sets, subsets, and binomial coefficients
Power set
The power set \(\mathcal{P}(X)\) is the set of all subsets of \(X\). If \(|X|=n\), then \(|\mathcal{P}(X)|=2^n\).
Binomial coefficient
For integers \(n\ge 0\) and \(0\le k\le n\), \(\binom{n}{k}\) is the number of \(k\)-element subsets of an \(n\)-element set: \[ \binom{n}{k}=\frac{n!}{k!(n-k)!}. \] By convention, \(\binom{n}{k}=0\) if \(k < 0\) or \(k > n\), and \(\binom{n}{0}=\binom{n}{n}=1\).
Pascal's identity
A \(k\)-element subset of \(\{1,\ldots,n\}\) either contains \(n\) or does not: \[ \binom{n}{k}=\binom{n-1}{k}+\binom{n-1}{k-1}. \]
Binomial theorem
For a non-negative integer \(n\), \[ (x+y)^n=\sum_{k=0}^{n}\binom{n}{k}x^{n-k}y^k. \] In particular, \(\sum_{k=0}^{n}\binom{n}{k}=2^n\).
11. Permutations and combinations
Permutation
An ordered arrangement of \(n\) distinct objects. There are \(n!\) such arrangements. The number of injective maps from a \(k\)-element set to an \(n\)-element set is \(P(n,k)=n(n-1)\cdots(n-k+1)=n!/(n-k)!\).
Combination
An unordered selection. The number of ways to choose \(k\) objects from \(n\) is \(\binom{n}{k}\), and \(P(n,k)=k!\binom{n}{k}\).
Selections with repetition
The number of ways to choose \(k\) elements from \(n\) types, with repetition allowed and order ignored, is \(\binom{n+k-1}{k}\). This is also the number of non-negative integer solutions of \(x_1+\cdots+x_n=k\).
Multinomial coefficient
The number of ways to partition \(n\) distinct objects into labelled groups of sizes \(n_1,\ldots,n_r\), where \(n_1+\cdots+n_r=n\), is \(\frac{n!}{n_1!\cdots n_r!}\).
12. Pigeonhole principle
Pigeonhole principle
If \(n\) objects are placed in \(k\) boxes, some box contains at least \(\lceil n/k\rceil\) objects. In particular, placing \(n+1\) objects in \(n\) boxes puts at least two in the same box.
13. Inclusion-exclusion
Two sets
For finite sets \(A\) and \(B\), \[ |A\cup B|=|A|+|B|-|A\cap B|. \]
Finite families
For finite sets \(A_1,\ldots,A_n\), \[ \left|\bigcup_{i=1}^{n}A_i\right| =\sum_i|A_i|-\sum_{i\lt j}|A_i\cap A_j| +\sum_{i\lt j\lt k}|A_i\cap A_j\cap A_k|-\cdots +(-1)^{n+1}|A_1\cap\cdots\cap A_n|. \] Intersections of an odd number of sets are added and those of an even number are subtracted.
Derangements
A derangement is a permutation with no fixed point. Inclusion-exclusion gives \[ !n=n!\sum_{k=0}^{n}\frac{(-1)^k}{k!}, \] the integer nearest to \(n!/e\) for \(n\ge 1\).
