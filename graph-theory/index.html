Graph Theory

Vertices, edges, and the cycles that run through them

A graph is a set of points together with a set of connections between them. Once that is in place, one can ask which routes exist, which cycles close, and when a cycle is the only one of its kind.

1. What is a Graph?

A graph is a mathematical structure consisting of vertices and edges. Formally it is written

\[ G = (V, E) \]

where \( V \) is the set of vertices and \( E \) is the set of edges. An edge joins two vertices. If those two vertices are allowed to be the same, the edge is a loop. If more than one edge may join the same pair, the graph is a multigraph. A simple graph has neither loops nor multiple edges.

A walk is a sequence of vertices in which each consecutive pair is joined by an edge. A cycle returns to its start and repeats no vertex in between.

2. Hamiltonian and Eulerian Graphs

A graph is Hamiltonian if it contains a cycle \( v_1 \to v_2 \to \cdots \to v_n \to v_1 \) that visits every vertex exactly once.

A graph is Eulerian if it contains a closed walk that uses every edge exactly once. Euler’s characterisation is classical: a connected graph has an Eulerian circuit if and only if every vertex has even degree.

Hamiltonian cycles have no such simple test. The name comes from Hamilton’s Icosian game on the dodecahedron; the Eulerian side goes back to the seven bridges of Königsberg.

3. Uniquely Hamiltonian Graphs

A graph is uniquely Hamiltonian when it has exactly one Hamiltonian cycle: one set of edges that forms a cycle through every vertex.

Cycle graphs are the trivial examples. For regular graphs the picture is a conjecture of Sheehan (1975): the only simple regular uniquely Hamiltonian graphs are the 2-regular ones, that is, the cycle graphs themselves. The odd-regular case is settled; the even-regular case, beginning at 4-regular graphs, remains open.

Fleischner constructed uniquely Hamiltonian 4-regular multigraphs from the Petersen graph, by way of an Eulerian \( (4,6) \)-regular graph. Whether that construction extends to other snarks is a separate question; the notes here treat it as an open line of work.
